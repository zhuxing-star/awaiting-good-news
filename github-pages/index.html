希望新的一岁里，你还是可以一直对这个世界保持好奇，去看想看的风景，做想做的事情，也希望生活能对你温柔一点。

本来挺想当面和你说一句生日快乐的，但现在也没办法去找你，只能先用文字，以这样的方式把祝福送给你。虽然隔着挺远，但好在想说的话还是能够传到你那里。

我们确实好久没见了，也好久没有认真聊过天。其实有几次想找你说说话，点开聊天框以后，却又不知道应该怎么开口，想了半天，最后还是什么都没发出去。

有时候想想，还真有点应了那句“旧人不知我近况”。

我不知道你现在在甘肃过得怎么样，工作顺不顺利，有没有遇到什么烦心事，也不知道那边最近冷不冷。偶尔也会好奇，你现在每天都在做些什么，有没有认识新的朋友，有没有发现什么好吃的东西，或者遇到一些让你觉得生活还不错的小事情。

既然不知道应该从哪里问起，那我就先讲讲我最近的事情吧。

不知不觉已经上了六个多月的班了。要说顺利，好像也确实挺顺利的。到现在公司前前后后差不多来了十来个实习生，最后只有我一个人比较顺利地留了下来。刚开始知道的时候，还是有一点开心的，至少说明这段时间做的事情得到了认可，也不算白忙活。

但要说不顺利，好像也有不少。

每天上班都会碰到各种各样的问题。早上到了公司，往位置上一坐，基本就是一整天。有时候忙起来，一抬头才发现天都已经黑了。

现在做的很多事情也开始变得重复。每天看起来都很忙，但仔细想想，好像只是在反复处理差不多的问题，真正能学到的新东西越来越少。比起单纯的累，这种明明一直在做事、却感觉自己没有继续往前走的状态，反而更让人有危机感。

有时候下班走在路上，我也会想，自己是不是应该做点改变。可真要说具体应该往哪里走，我暂时也没有完全想清楚。大概就是一边焦虑，一边继续把眼前的事情做好，再慢慢找接下来的方向。

前面放的那些照片，也都是这一段时间里随手拍下来的。有杭州的西湖、雷峰塔和音乐喷泉，也有灵隐寺下雨时的伞、雨铃和小路，还有后来去绍兴时看到的小河和巷子。

它们原本只是安安静静地放在相册里。后来准备这份生日祝福的时候，我重新翻了一遍，突然觉得，与其只对你说一句简单的“生日快乐”，不如也把这一段时间里见过的一些风景分享给你。

就当作是把这段时间没来得及说的话，慢慢讲给你听吧。
